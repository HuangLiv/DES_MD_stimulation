For manuscript use, this folder should be used for dynamic distance/contact metrics only:
- protein-ligand COM distance
- protein-ligand minimum distance
- contact occupancy at 0.35, 0.45, and 0.60 nm cutoffs

Hydrogen-bond data used in the manuscript come from standard_md_analysis, where gmx hbond-legacy completed successfully. The optional gmx hbond selection-mode outputs and interaction-energy rerun logs in older dynamic-analysis runs were diagnostic/failed optional analyses and were not used for the manuscript conclusions.
